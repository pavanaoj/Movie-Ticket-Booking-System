# 🎬 Movie Ticket Booking System

A simple **Movie Ticket Booking System** developed using **Python and SQLite**.

## 📌 Project Description

This project allows users to view available movies and shows, book movie tickets, view bookings, and cancel bookings.

The system uses **SQLite database**, so no separate MySQL installation is required.

## 🚀 Features

- 🎥 View available movies
- 🕐 View available shows
- 🎟️ Book movie tickets
- 📋 View all bookings
- ❌ Cancel bookings
- 💾 Store booking information using SQLite
- 🔒 Prevent duplicate seat bookings

## 🛠️ Technologies Used

- Python
- SQLite
- SQL
- GitHub
